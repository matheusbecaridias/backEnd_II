# Programação Back-End II

Este repositório é dedicado ao armazenamento de códigos, exercícios e projetos desenvolvidos na unidade curricular de **Programação Back-End II**. A disciplina foca no aprofundamento da lógica de servidor, integração com bancos de dados e o uso de arquiteturas modernas para o desenvolvimento de sistemas robustos [2, 3].

## 📋 Sobre a Disciplina
A disciplina possui uma carga horária de **133 horas relógio** (160 aulas semestrais), com foco no desenvolvimento de competências para codificar aplicações complexas, realizar testes funcionais e implementar segurança em nível de servidor [2, 3].

*   **Semestre:** 3º Semestre
*   **Carga Horária Semanal:** 4 aulas [2]

## 🎯 Objetivos e Habilidades
*   **Programação Avançada:** Dominar paradigmas de programação, com ênfase em Orientação a Objetos e scripts server-side [2, 3].
*   **Integração de Sistemas:** Desenvolver e consumir APIs para comunicação com interfaces front-end [2, 3].
*   **Gestão de Dados:** Implementar conexões eficientes e seguras com bancos de dados [2, 3].
*   **Colaboração:** Utilizar frameworks e ferramentas que facilitem o trabalho em equipe e a manutenção de registros para análise de resultados [2, 3].

## 📚 Conteúdo Programático
A disciplina abrange os seguintes tópicos principais:
1.  **Programação Orientada a Objetos (Java):**
    *   Classes, objetos, atributos e métodos.
    *   Modificadores de acesso (público, privado, protegido).
    *   Encapsulamento, Herança e Polimorfismo.
    *   Classes Abstratas [2, 3].
2.  **Ambiente Server-Side e Javascript:**
    *   Comunicação via Request e Response.
    *   Comunicação assíncrona de threads.
    *   Criação e gerenciamento de módulos [2, 3].
3.  **Desenvolvimento de APIs:**
    *   Criação de APIs aplicadas na comunicação com o front-end [2, 3].
    *   Segurança e acessibilidade em nível de back-end [2, 3].

## 🛠️ Tecnologias e Ferramentas
*   **Linguagens Principais:** Java e JavaScript [2, 3].
*   **Ambientes:** Node.js (conforme bibliografia sugerida) e Java JDK [4].
*   **Banco de Dados:** Conexão com SGBDs relacionais [2, 3].

## 📝 Avaliação
Seguindo as diretrizes de **Metodologias Ativas** do curso, a avaliação baseia-se na capacidade do estudante de mobilizar conhecimentos para resolver situações-problema reais através de [5-7]:
*   Desenvolvimento de rotinas e aplicações funcionais.
*   Entrega de documentação técnica de apoio.
*   Realização de testes de software para garantir a confiabilidade dos sistemas [3].
